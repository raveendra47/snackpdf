# Privacy

SnackPDF processes selected documents locally in the browser. Documents are not intentionally transferred to SnackPDF for processing. There are no user accounts, document storage service, analytics, advertising trackers, behavioural profiles or document processing API.

Normal website delivery can expose network information such as an IP address to the hosting infrastructure when the application itself is downloaded. Managed hosting may also apply a short-lived anti-abuse cookie. SnackPDF application code does not put document contents, filenames, passwords or document hashes into requests.

After the application has been cached successfully, the tools can work offline. The application cache stores the program itself, not users' documents. SnackPDF cannot recover a document after the tab is closed because it never receives a copy.
