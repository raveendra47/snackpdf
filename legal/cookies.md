# Cookies

SnackPDF application code does not create cookies. The current managed hosting security layer may set a short-lived `__cf_bm` cookie to distinguish ordinary requests from automated traffic. SnackPDF does not use it for advertising, analytics or personalisation, and it does not contain document content.

The browser may store SnackPDF application files so the website can continue working offline. Those cached application files do not contain users' documents. A direct deployment using the supplied static-server configuration does not require an application cookie.
